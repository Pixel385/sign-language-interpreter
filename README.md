# "Sign-language interpreter" (Цифровой сурдопереводчик)

## 1. Описание проекта
Проект представляет собой систему распознавания жестового алфавита с использованием технологий искусственного интеллекта и компьютерного зрения. Камера фиксирует жест человека в режиме реального времени, после чего CNN определяет соответствующую букву и выводит её на экран.

## 2. Цель(Актуальность) и проблематика проекта
**Проблематика:** Глухонемые люди испытывают серьезный барьер в общении с теми, кто не владеет языком жестов . Существующие технологические решения часто опираются на аппаратные средства — сенсорные перчатки или камеры глубины(Kinect, Intel RealSense), что делает их дорогими и недоступными для массового пользователя.

**Цель:** Разработка доступного программного решения, способного распознавать жестовый язык в режиме реального времени, используя исключительно стандартную веб-камеру ПК.

* **Задачи:**
1. Изучить базовые принципы работы со сверточными нейронными сетями (CNN).
2. Подготовить и предобработать набор данных (датасет) изображений жестов.
4. Обучить модель на базе выбранного фреймворка (TensorFlow/Keras).
5. Разработать модуль захвата видеопотока с камеры и интеграции с обученной моделью.
6. Обеспечить высокую точность распознавания при нестабильном освещении и на фоне сложных текстур, не перегружая при этом центральный процессор.

## 3. Датасет
Папку с датасетом можно скачать перейдя по данной ссылке: https://www.kaggle.com/datasets/debashishsau/aslamerican-sign-language-aplhabet-dataset
* **Описание данных:** Датасет содержит изображения (массивы пикселей) рук, показывающих буквы жестового алфавита.
* **Подготовка датасета:**
Для успешного распознавания жеста нейросетью, сырой кадр с веб-камеры проходит строгий алгоритм нормализации, реализованный связкой MediaPipe и OpenCV:
Кадрирование: С помощью MediaPipe система находит крайние точки пальцев и запястья, вычисляя точные границы руки. К этим границам математически добавляется отступ (Padding) в 30 пикселей, чтобы гарантировать, что кончики пальцев не будут обрезаны.
Умное масштабирование: Нейросеть требует на вход квадратную матрицу 64x64 пикселя. Если прямоугольный срез руки просто сжать, пропорции пальцев исказятся, и модель не узнает жест. В нашем коде реализован алгоритм «Умного сжатия»: программа создает квадратную матрицу по размеру самой длинной стороны среза, помещает вырезанную руку строго по центру этого квадрата, и только затем сжимает. Это сохраняет естественную геометрию руки.

## 4. Используемые технологии
Для реализации проекта запланирован следующий стек технологий:
* **Язык программирования:** Python
* **Компьютерное зрение:** OpenCV (cv2) - В проекте отвечает за:
Захват кадров с веб-камеры в реальном времен.
Обработка кадров(изменение цветового кода RGB-BGR, сохранение нужных пропорций, вырезание руки из кадра)
* MediaPipe - Используется для сверхбыстрого трекинга кисти в кадре. Нейросеть находит 21 ключевую точку суставов, на основе которых мы математически высчитываем динамическую рамку (Bounding Box) для вырезания руки.
* **Машинное обучение и Нейросети (Deep Learning & ML)**
TensorFlow / Keras - В проекте он является "мозгом" системы и отвечает за движок глубокого обучения.
Scikit-Learn - Превращает текстовые названия папок с жестами (классы) в числовые векторы для нейросети и расшифровывает их обратно.
* **Графический интерфейс пользователя (GUI)**
CustomTkinter (ctk) - современная библиотека для создания графических интерфейсов. 
Pillow (PIL) - библиотека для работы с растровой графикой. Конвертирует математические матрицы изображений из OpenCV в формат, который может быть отрисован на экране в интерфейсе CustomTkinter.
* **Обработка данных и математика (Data & Core)**
NumPy (np) - Отвечает за нормализацию пикселей (деление на 255), изменение размерности тензоров перед подачей в нейросеть (reshape) и поиск максимальной вероятности (argmax).

## 5. Модель ИИ и Оптимизация памяти
Сердцем системы является Сверточная нейронная сеть (CNN).
* **Архитектурные особенности:** В модель внедрены слои пакетной нормализации (BatchNormalization). Они делают сеть более устойчивой к изменениям освещения и цвета фона на реальной веб-камере.
* **Решение проблемы Big Data:** Обучающая выборка содержит сотни тысяч изображений. Чтобы избежать ошибки переполнения оперативной памяти (MemoryError), мы внедрили генераторы потоковой загрузки (flow_from_directory). Данные подгружаются с жесткого диска в ОЗУ частями (по 32 кадра), нормализуются и сразу отправляются в процессор.
* **Аугментация:** При обучении генератор искажает исходные данные (повороты на 15 градусов, сдвиги, зум), что виртуально увеличивает объем датасета и защищает модель от переобучения.
