# "Sign-language interpreter"
# 1. Описание
Проект представляет собой распознавания жестового алфавита с использованием технологий искусственного интеллекта и компьютерного зрения. Камера фиксирует жест человека, после чего нейронная сеть определяет соответствующую букву и выводит её на экран.

#  2. Цель проекта
Создать цифрового сурдопереводчика, способного распознавать жесты пользователя через камеру и преобразовывать их в текст в режиме реального времени
