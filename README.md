# "Sign-language interpreter" (Цифровой сурдопереводчик)

## 1. Описание проекта
Проект представляет собой систему распознавания жестового алфавита с использованием технологий искусственного интеллекта и компьютерного зрения. Камера фиксирует жест человека в режиме реального времени, после чего CNN определяет соответствующую букву и выводит её на экран. Это позволяет создать удобный мост коммуникации для людей с нарушениями слуха и речи.

## 2. Цель и задачи проекта
**Цель:** Создать цифрового сурдопереводчика, способного распознавать жесты пользователя через веб-камеру и преобразовывать их в текст в режиме реального времени.

**Задачи:**
1. Изучить базовые принципы работы со сверточными нейронными сетями (CNN).
2. Подготовить и предобработать набор данных (датасет) изображений жестов.
3. Спроектировать архитектуру нейронной сети и провести её математический анализ.
4. Обучить модель на базе выбранного фреймворка (TensorFlow/Keras).
5. Разработать модуль захвата видеопотока с камеры и интеграции с обученной моделью.
6. Оформить результаты, подготовить отчет и презентацию для защиты.
