# "Sign-language interpreter" (Цифровой сурдопереводчик)

## 1. Описание проекта
Проект представляет собой систему распознавания жестового алфавита с использованием технологий искусственного интеллекта и компьютерного зрения. Камера фиксирует жест человека в режиме реального времени, после чего CNN определяет соответствующую букву и выводит её на экран.

## 2. Цель(Актуальность) и проблематика проекта
**Проблематика:** Люди с нарушениями слуха и речи сталкиваются с барьером в общении. Существующие аналоги требуют дорогого оборудования (сенсорные перчатки, камеры глубины), что делает их недоступными для массового пользователя.

**Цель:** Создать доступное ПО для распознавания жестового языка в реальном времени, работающее через обычную веб-камеру любого ПК.
* **Задачи:**
1. Исследовать принципы работы сверточных нейросетей (CNN).
2.Собрать и предобработать датасет с изображениями жестов.
4. Обучить модель на базе выбранного фреймворка (TensorFlow/Keras).
5. Разработать модуль захвата видеопотока с камеры и интеграции с обученной моделью.
6. Оптимизировать систему для стабильной работы на сложных фонах и при слабом освещении без высокой нагрузки на процессор.

## 3. Датасет
Папку с датасетом можно скачать перейдя по данной ссылке: https://www.kaggle.com/datasets/debashishsau/aslamerican-sign-language-aplhabet-dataset
* **Описание данных:** Датасет содержит изображения (массивы пикселей) рук, показывающих буквы жестового алфавита.
* *Количество уникальных жестов (классов):* 23
* *Общий объем данных:* 4,24 ГБ

## 4. Используемые технологии
Для реализации проекта запланирован следующий стек технологий:
* **Язык программирования:** [Python]()
* **Компьютерное зрение:** [OpenCV (cv2)](https://opencv.org/) - В проекте отвечает за:
Захват кадров с веб-камеры в реальном времен.
Обработка кадров(изменение цветового кода RGB-BGR, сохранение нужных пропорций, вырезание руки из кадра)
* [MediaPipe](https://pythonlib.ru/library-theme99) - Используется для сверхбыстрого трекинга кисти в кадре. Нейросеть находит 21 ключевую точку суставов, на основе которых мы математически высчитываем динамическую рамку (Bounding Box) для вырезания руки.
* **Машинное обучение и Нейросети (Deep Learning & ML)**
[TensorFlow / Keras](https://www.tensorflow.org/guide/keras?hl=ru) - В проекте он является "мозгом" системы и отвечает за движок глубокого обучения.
[Scikit-Learn](https://scikit-learn.org/stable/index.html) - Превращает текстовые названия папок с жестами (классы) в числовые векторы для нейросети и расшифровывает их обратно.
* **Графический интерфейс пользователя (GUI)**
[CustomTkinter (ctk)](https://scikit-learn.org/stable/index.html) - современная библиотека для создания графических интерфейсов. 
[Pillow (PIL)](https://pillow.readthedocs.io/en/stable/index.html) - библиотека для работы с растровой графикой. Конвертирует математические матрицы изображений из OpenCV в формат, который может быть отрисован на экране в интерфейсе CustomTkinter.
* **Обработка данных и математика (Data & Core)**
[NumPy (np)](https://pillow.readthedocs.io/en/stable/index.html) - Отвечает за нормализацию пикселей (деление на 255), изменение размерности тензоров перед подачей в нейросеть (reshape) и поиск максимальной вероятности (argmax).

## 5. Модель ИИ и Оптимизация памяти
![](https://github.com/Pixel385/sign-language-interpreter/blob/main/SignLanguageTranslator/architecture.jpeg)
Сердцем системы является Сверточная нейронная сеть (CNN).
* **Архитектурные особенности:** В модель внедрены слои пакетной нормализации (BatchNormalization). Они делают сеть более устойчивой к изменениям освещения и цвета фона на реальной веб-камере.
* **Решение проблемы Big Data:** Обучающая выборка содержит сотни тысяч изображений. Чтобы избежать ошибки переполнения оперативной памяти (MemoryError), мы внедрили генераторы потоковой загрузки (flow_from_directory). Данные подгружаются с жесткого диска в ОЗУ частями (по 32 кадра), нормализуются и сразу отправляются в процессор.
* **Аугментация:** При обучении генератор искажает исходные данные (повороты на 15 градусов, сдвиги, зум), что виртуально увеличивает объем датасета и защищает модель от переобучения.

## 7.Метрики обучения:

* *Количество эпох обучения:* 15
* *Точность классификации при тестировании (Accuracy):* 94,6%

$TP$ (верно угадано), $TN$ (верно отвергнуто), $FP$ (ложная тревога) и $FN$ (пропуск цели).Accuracy (Общая точность): Доля правильных ответов по всем жестам.

$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$

## 8.Компьютерное зрение:

*Границы кадрирования (отступ вокруг кисти):* 30 пикселей
*Порог уверенности обнаружения объекта (Detection Confidence):* 50%

* *Логика предсказаний (Инференс):*

*Минимальный порог уверенности классификатора:* > 80%

*Временная стабилизация видеопотока:* буферизация 15 кадров (итоговый результат выводится на основе усреднения или наиболее частого совпадения за последние 15 распознанных кадров)
* $$R_{final} = \text{mode}(\{R_1, R_2, \dots, R_{15}\})$$
